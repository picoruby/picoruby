SQLite3 TODO app

A TODO list backed by a real SQLite3 database running inside picoruby.wasm. The working database lives entirely in memory, so every add / toggle / delete is an ordinary SQL statement. Persistence is explicit: nothing is written to browser storage until you press Save to IndexedDB. Reload the page to confirm that only saved changes survive.

    saved

    How it works

    SQLite3::Database.new("todos") opens an in-memory database and restores the last snapshot saved under that name from IndexedDB. SQL runs synchronously against that memory database. Pressing Save to IndexedDB calls db.persist, which serializes the whole database and writes it to IndexedDB at a Ruby await point. The GC never persists, and this demo does not auto-persist on close, so unsaved edits are lost on reload.
